نظام رسائل موزع يعتمد على الأحداث (Event-Driven Messaging System)

معمارية سحابية متكاملة لربط واجهات البرمجيات بطوابير الرسائل، مع معالجة خلفية آمنة وإدارة الأخطاء.

FastAPI→ AWS SQS→ Lambda Handler→ DLQ (Error Handling)→ DynamoDB
  • تمت هندسة وبناء كافة الموارد برمجياً باستخدام Terraform والاختبار المحلي عبر LocalStack.
  • تطبيق معايير الاعتمادية العالية عبر طوابير الرسائل الفاشلة (Dead Letter Queues) لضمان عدم ضياع البيانات.
  • أتمتة عملية النشر والتحقق عبر مسارات GitHub Actions المتكاملة.
